# Sheikh Sons Company — Super Home Care Products

Complete static website package ready for GitHub Pages or any static web host.

## Included
- Home, About, Products, Dealer Inquiry, Contact and Privacy pages
- 35 individual product detail pages
- 10 product category pages
- Product images in PNG/JPG and optimized WebP
- CSS and JavaScript
- Product data JSON
- Original supplied product catalogue under `assets/docs/`
- WhatsApp inquiry integration for `0301-8968861`
- `robots.txt` and `sitemap.xml`

## GitHub Pages
1. Create a GitHub repository.
2. Upload **the contents of this folder** to the repository root. `index.html` must be at the root.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
